# Severance: Snakes and Ladders 🐍🎲

Missing Severance now that Season 2 is over? This twist on the classic Snakes and Ladders game brings you into the world of Lumon Industries.

Built with **React** and **Redux**, you can play solo against the computer or go head to head with a friend.

## Preview

[![Watch a short demo](https://img.youtube.com/vi/sz23N6BwlHI/0.jpg)](https://www.youtube.com/watch?v=sz23N6BwlHI)


## Features

- Themed board inspired by *Severance*
- Two game modes: 1v1 Local or solo vs Computer
- Game state management via Redux
- Animation for numbers, rolls and player movement

## Tech Stack

- React
- Redux Toolkit
- JavaScript
- CSS Modules / Tailwind

## Getting Started
```bash
yarn install
yarn start
```
